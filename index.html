Welcome to Online Book Store

This web application is designed for online purchasing using HTML, CSS, JavaScript, and XML.


You can perform the following actions:

  • Register: Create a new user account with client-side JavaScript form validation.
  • Login: Sign in with username and password verification.
  • Catalogue: Browse books dynamically retrieved from an products.xml file.
  • Cart: Add books to your shopping cart, review total cost, and place an order.
